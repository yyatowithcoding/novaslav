Import

Add new words straight into the live dictionary. Type them in below or upload a .txt file, either way uses the same format.

Format

One word per line, fields separated by commas:

word, english, category[, gender]

Word is written in Novôslav's Latin alphabet, plain letters plus the accented ones (ô, š, č, ď, ť, ľ, ň) where needed.
Category is one of: Pronouns, Verbs, Nouns, Adjectives, Numbers, Question Words, Adverbs, Prepositions, Conjunctions, Interjections, Conversational.
Gender only matters for Nouns ("common" or "neuter", defaults to common) and controls the definite suffix (-en / -et).
For Nouns, the definite form and for Verbs, the past tense, get worked out automatically using the site's own grammar rules, you don't need to type them.
Lines starting with # are ignored, handy for comments.
Guardrail: the same Novaslav spelling can't be reused for two different meanings, whether the clash is against another line in the same import or a word already in the dictionary. Those lines get rejected with an error instead of silently creating a duplicate.

Example:

# a noun (definite form "kotet" gets worked out for you)
kot, cat, Nouns, neuter

# a verb (past tense "čitde" gets worked out for you)
čitar, read, Verbs
